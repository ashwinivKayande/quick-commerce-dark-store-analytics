# Quick Commerce Dark Store Performance & Stock-out Analytics

End-to-end analytics project: synthetic data -> MySQL -> SQL analysis -> Power BI dashboard.

## Dataset
Synthetic dataset designed and generated by me (Python: numpy, pandas).
7 tables, ~3.7 lakh rows, Jan-Jun 2026, 12 dark stores across Bengaluru, Delhi, Hyderabad, Mumbai.
Built-in patterns: evening peak (6-9 PM), rain adds ~5 min to delivery, store-specific stock-outs.

## Tools
Python, MySQL 8, Power BI Desktop (DAX), Power Query.

## Files
- generate_data.py : creates the dataset (seed 42, reproducible)
- sql/01_schema.sql : database, tables, keys, indexes
- sql/02_analysis_queries.sql : 11 analysis queries (CTEs, RANK, LAG, NTILE)
- sql/03_views.sql : reporting views (orders, sales, inventory, RFM, store P&L)
- dark_store_dashboard.pbix : Power BI report (6 pages)
- dark_store_dashboard.pdf : dashboard export

## Dashboard pages
Overview | Delivery & Profitability | Inventory & Stock-out | Customers (RFM) | Insights | Store Detail (drill-through)

## Key features
DAX time intelligence (MoM growth, running total), what-if parameter (rider cost),
conditional-format heatmap, drill-through, page navigation.

## Key findings
- 90% of orders are late on rainy days vs 29% on dry days.
- Andheri and Rohini are net-negative after rider cost and rent.
- Madhapur loses 28% of Fruits & Veg and 25% of Dairy days to stock-outs.
- Champions spend Rs 2,114 on average vs Rs 394 for Lost customers.

Note: all data is synthetic; findings illustrate the analysis approach.
